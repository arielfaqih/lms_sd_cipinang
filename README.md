# LMS Offline IPAS (bagian IPA) Kelas 4–6 · SDN Cipinang II

LMS lokal untuk guru IPAS: menyajikan materi tanpa internet, membuat soal dengan AI (Gemini), dan mengelola bank soal.

Di SD kelas 3–6, mata pelajarannya adalah **IPAS** (IPA dan IPS digabung). LMS ini memuat **bagian IPA** dari CP IPAS (Keputusan Kepala BSKAP No. 046/H/KR/2025). Topik IPS dari CP belum disertakan.

**Mulai cepat (Windows):** pasang Node.js LTS, lalu klik dua kali `mulai-server.bat`. Masuk dengan `admin` / `admin123`.

Panduan lengkap pemasangan, panduan guru bergambar, dan catatan teknis ada di **[PANDUAN.md](PANDUAN.md)**.
